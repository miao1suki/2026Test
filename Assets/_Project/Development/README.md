# Development content

This directory is only for disposable system sandboxes, experiments and automated-test support.

- Put reusable system test scenes under `Sandbox/Systems/<SystemName>`.
- Do not keep the only copy of a real level here.
- Do not add development sandboxes to an enabled player build.

Editable level scenes now live under `Assets/_Project/Scenes/Levels`. The removed piece/total-2D/folded-3D authoring pipeline is no longer part of the project.
