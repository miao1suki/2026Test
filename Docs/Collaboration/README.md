# 2026Test 协作手册入口

团队先阅读以下文件：

1. [团队协作总流程](TEAM_WORKFLOW.md)：项目结构、场景拆分、职责边界、集成和构建规则。
2. [角色工作卡](ROLE_WORKFLOWS.md)：可单独复制给玩法策划、策划程序、关卡策划、程序、TA、整合者以及非 Git 美术/音频成员。
3. [任务与交接模板](TASK_AND_HANDOFF_TEMPLATES.md)：派发任务、AI 提示、分支交接、场景负责人、玩法需求、TA 管线申请和构建记录。

当前执行摘要：

- 不使用对象锁定或文件锁定工具。
- 同一个 Scene、Prefab 或 Data 在一个任务周期内只安排一名编辑负责人。
- 所有 Git 成员使用 `$unity-git-branch-worker`，只推送自己的任务分支。
- 最终合并由整合者完成。
- 整合者和主程都可以打包；正式包必须来自指定的 `origin/main` SHA，并由整合者验收。

文档中的 `Assets/_Project` 是目标结构，当前项目尚未执行资源迁移。迁移时应由整合者创建独立任务，避免多人同时移动 Unity 资源和 `.meta`。
