# 立方体地图编辑器

## 1. 当前范围

本工具把关卡策划在平面中搭建的地图，按“正前、正右、正后、正左”的顺序
折叠成立方体四个侧面。本阶段只负责地图拆分、2D 总拼、3D 拼合与场景导航，
不生成钥匙、奖品、起点、终点或其他玩法内容。

默认工作区为 `LV001`：

- 单个“小拼图 Scene”代表一关（或一层），内部横向放置四个面；
- 多个小拼图 Scene 纵向组合成 2D 总拼；
- 同一批小拼图直接围绕 Y 轴折叠，生成 3D 主场景；
- 2D 总拼与 3D 拼合区域均以 `[GENERATED] Cube Map` 标记，可重复生成；
- 小拼图 Scene 是唯一人工编辑源，生成操作不会修改源场景。

## 2. Scene View HUD

重新编译后，Scene View 四角会显示 UI Toolkit HUD：

- 左上：打开 2D 总拼、打开 3D 主场景、定位工作区参数；
- 右上：选择、打开或新建独立小拼图 Scene；
- 左下：显示或隐藏分面色块、面名与分格线；
- 右下：刷新 2D 总拼，或拼合并打开 3D 主场景。

第一次使用点击“初始化 LV001 地图工作区”。工具会创建四个默认小拼图、
2D 总拼场景、3D 主场景和一个工作区配置资产。已存在的文件不会被覆盖。

## 3. 多人协作方式

每名策划只领取一个小拼图 Scene，例如：

```text
Assets/_Project/Scenes/Levels/LV001/Pieces/LV001_Piece_01.unity
Assets/_Project/Scenes/Levels/LV001/Pieces/LV001_Piece_02.unity
```

策划把物体放在该 Scene 的对应层级下：

```text
LV001_Piece_01_Authoring
├── Face_01_Front_正前/Content
├── Face_02_Right_正右/Content
├── Face_03_Back_正后/Content
└── Face_04_Left_正左/Content
```

不要直接修改 2D 总拼或 3D 主场景中 `[GENERATED] Cube Map` 下的内容，
因为下次生成会替换该根节点。集成人员拉齐各策划分支后，再刷新总拼和 3D。

## 4. 坐标与折叠规则

2D 中四个面从左到右排列：正前、正右、正后、正左。每一关从下向上叠放。
拼合为 3D 后：

| 面 | 3D 位置 | Y 轴旋转 |
| --- | --- | --- |
| 正前 | `Z = -FaceWidth / 2` | `0°` |
| 正右 | `X = +FaceWidth / 2` | `-90°` |
| 正后 | `Z = +FaceWidth / 2` | `180°` |
| 正左 | `X = -FaceWidth / 2` | `+90°` |

物体相对各自 `Face_*` 根节点的位置、旋转、缩放和组件会被完整复制。
默认每面宽 12、每关高 4、每面横向 6 格、每关纵向 2 格；这些参数可在
工作区配置资产中修改。

## 5. 验收清单

1. 四个默认小拼图可以分别打开和保存；
2. 2D 总拼按关数从下向上排列，四面颜色与标签一致；
3. 3D 主场景形成闭合的四侧结构，面顺序没有镜像或错位；
4. 重复生成只替换 `[GENERATED] Cube Map`，不影响相机、灯光或其他主场景内容；
5. 源小拼图中的对象与层级保持不变；
6. 不同策划只编辑不同小拼图时，不会同时修改同一个 Scene 文件。
