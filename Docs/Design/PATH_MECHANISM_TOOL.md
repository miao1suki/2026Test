# 绳子、梯子与平台编辑工具

## 给策划的最短流程

1. 打开自己负责的 Scene。
2. 如果面板没有显示，选择 `Tools > 2026Test > 路径机关 > 显示傻瓜式 Scene 工具`。
3. 在 Scene 视图右侧点击 `＋ 绳子`、`＋ 梯子` 或 `＋ 平台`。
4. 选中一条绳子后，可以从 A/B 端连续创建；选中梯子后，可以向上/向下连续创建。
5. 新平台会自动绑定当前绳子端点；未选绳子时会绑定最近端点；场景没有绳子时会先自动创建一条。
6. 拖动对象或端点调整位置。需要检查时点击 `检查并修复当前场景`。
7. 保存自己的 Scene 并提交，不需要生成 2D 总拼或 3D 拼合场景。

创建位置优先采用当前选中对象的位置；没有选择时采用 Scene 视图中心。网络根对象、白膜、平台碰撞体和绑定引用由工具自动补齐。所有创建操作支持 Undo。

## 预览与修正

- `2D 视角方向` 同时控制绳子和梯子的连接预览方向。
- 绳子端点可以使用投影吸附或实体吸附。
- 梯子只连接同一可见面族：正面/背面互连，左面/右面互连，正面不与侧面连接。
- `检查并修复当前场景` 会收纳游离机关、补白膜和平台碰撞体、刷新路径缓存，并报告未绑定平台。

## 运行时边界

编辑工具只负责创建和连接数据，不接管角色或平台移动逻辑。

- 绳子运行时 API：见 [ROPE_PATH_EDITOR.md](ROPE_PATH_EDITOR.md)。
- 梯子与玩家攀爬接口：见 [LADDER_PATHS.md](LADDER_PATHS.md)。
- 平台通过 `RopePlatform` 获取绑定的 `RopePathNetwork`、`RopeSegment` 和端点；移动实现仍由平台程序负责。
- 摄像机 2D/3D 切换保持独立：见 [CAMERA_CONTROL_MANAGER.md](CAMERA_CONTROL_MANAGER.md)。

## 场景协作

目前每个人直接新建并维护自己的 Scene，不使用旧的关卡数据块、2D 小拼、2D 总拼或折叠 3D 发布流程。不要多人同时保存同一个 `.unity` 文件；最后如何组合由整合者在关卡完成后决定。
